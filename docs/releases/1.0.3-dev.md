# Windows Search Redirector 1.0.3-dev

Pre-release, 2026-10-11. This is a development update, not a stability guarantee
across Windows builds or launcher versions.

## Changes

- Check for a responsive launcher window before intercepting search. For
  Command Palette, PowerToys running by itself is not enough.
- Improve foreground handoff without attaching input queues, forcing root
  focus or dismissing Start with Escape before the launcher takes over.
- Wait for a focused, enabled Command Palette input field before replaying text.
- Serialize capture completion with incoming input, replay Unicode in batches,
  suppress paired key releases and support externally injected Unicode input.
- Remove the additional 180 ms injection delay by default. Existing explicit
  settings remain unchanged; set `textCaptureDelayMs` to `0` to use the new
  default on an existing installation.
- Allow native search for five seconds after activation failure, and recover
  launch ownership if its Windows host process has terminated.
- Add a real-desktop regression harness, readable live logs and a read-only PDB
  inspection tool. Update the English and French documentation.

`x-cmdpal:` remains the primary activation path. No default PowerToys Run or
Command Palette keyboard-shortcut fallback is added.

## Verification and limitations

- The uninterrupted interactive series passed 11/11 cases: opening Start with
  Win, Ctrl+Esc and its taskbar button; search-bar clicks without typing; and
  fast typing through Start and Win+S. Queries matched exactly and no input
  reached the disposable previous window.
- Native Win+S and Start typing were separately verified with Command Palette
  stopped while PowerToys remained running.
- The final cleanup and dead-host recovery were compiled after that series,
  but did not receive a new complete interactive run. Crash recovery was not
  fault-injection tested.
- **Instant Start dismissal without animation remains unresolved.** The
  experimental dismissal hook is not included.
- Intermittent unwanted activation on opening Start is not claimed fixed on
  every system. Reports should include the mod version, Windows build and the
  exact opening gesture.
- Failure after interception still discards the current captured query instead
  of replaying it into an unrelated application. Subsequent requests can use
  native search; the first query is not automatically recovered.
- Paste, unresponsive-launcher fault injection, PowerToys Run, custom launchers,
  IME/dead-key composition and prolonged everyday use were not covered by the
  final runtime series.

Test environment: Windows 26340.9616, Windhawk 1.7.3, Command Palette
0.12.12601.0. See the [investigation report](../runtime-investigation-2026-10-11.md)
for evidence and reproduction commands.

## Installation

Use the attached `replace-windows-search.wh.cpp` as the source of a local
Windhawk mod, compile it and enable it. The complete mod remains self-contained
in this single file. The repository also includes the optional CLI toolchain.
